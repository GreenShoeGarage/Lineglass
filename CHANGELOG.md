# LINEGLASS Changelog

## 1.0.0 — 2026-08-18

Initial complete release.

- Added local-first project model, autosave state, IndexedDB session storage, import/export, and Fresh Start controls.
- Added Web Serial Port A/Port B connections, independent settings, reconnect, disconnect, forget, signal display, and line-signal controls.
- Added Monitor, Terminal, Request/Response, Dual-Port Tap, and Replay operating modes.
- Added byte-preserving capture with host-arrival timestamps, events, annotations, bookmarks, statistics, and bounded rendering.
- Added synchronized text, hex, and mixed views.
- Added configurable framing for delimiter, fixed-length, inactivity-gap, start/end, length-prefixed, COBS, and SLIP streams.
- Added Raw UART, Modbus RTU, Modbus ASCII, NMEA 0183, ASCII command/response, custom binary, and SLCAN decoders.
- Added unknown-protocol clustering, entropy/change analysis, candidate-field suggestions, integrity testing, correlation, and periodicity analysis.
- Added activity, sequence, numeric, traffic-rate, gap, histogram, byte-heatmap, and NMEA-track visualizations.
- Added linked frame inspection, filtering, baseline comparison, replay, command libraries, finite repetition, and emergency transmit stop.
- Added self-contained HTML evidence reports and SHA-256 capture hashes.
- Added ten internal demonstrations and matching external timestamped sample sessions.
- Added Easy/Advanced modes, dark/light/system/high-contrast themes, responsive panels, visible version, and embedded changelog.
